# MiBuscador

Página web con buscador integrado que redirige las consultas a Google. Cuenta con un fondo visual y diseño responsive.

## Estructura

- `index.html` — Página principal con formulario de búsqueda.
- `PixelYelanLite.png` — Imagen de fondo.
- `YelanAI.mp4` — Video de fondo.
- `styles.css` — Estilos externos.

## Uso

Abre `index.html` en un navegador, escribe tu consulta y presiona Enter. Se abrirá una nueva pestaña con los resultados de Google.
